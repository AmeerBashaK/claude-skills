# Logos and lettering

## Monoline logos (The Futur)
- Set guides first: cap height, x-height, baseline, letter widths (use H as the base width; N is H with a
  shorter stroke). Convert helper shapes to guides (Illustrator: Ctrl/Cmd+5).
- One stroke weight throughout; curves sit on guide circles; round caps/joins for a consistent line.
- Avoid "kinky" joins: keep tangents smooth; use smart guides and snapping; scale diagonals at 45° so angles stay
  consistent.
- Check the counters and spacing optically, not just mathematically.

## Hand lettering basics (Gemma O'Brien)
- Tools: brush pens, markers, ink. Thick downstrokes, thin upstrokes. Draw letters as shapes; don't "write" them.
- Sketch, refine, then vectorise (Illustrator image trace or redraw with the pen tool).

## Logo quality tests (Chris Do)
1. Passes the basic aesthetic test for strangers who don't know the brand story.
2. Simple: recognisable as a favicon and on a billboard; make a responsive set (full, compact, icon) if needed.
3. Versatile: works on a shirt, shoe, app icon, one colour, reversed out.
4. Mock it up in real applications and place it next to brands you admire; get consistent feedback from people
   with taste.
5. Timeless over trendy: proven geometric harmonies; evolve a logo, don't keep replacing it.
6. The value is the strategy and consistent rollout, not just drawing a mark (AI can draw a mark).
