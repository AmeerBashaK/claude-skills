**Claim:** a site that knows what type it is, has great appropriate imagery, excellent typesetting and a clear hierarchy beats about 95% of websites.

## 1. Know the website type, because it sets the goal
| Type | Examples | User goal → design goal |
|---|---|---|
| Shop | E-commerce | Buy |
| Media | YouTube, blogs, news (content changes constantly) | Read, watch, listen |
| Marketing | Product/service/studio sites | Get excited → **make an enquiry** |
| App | Facebook, Trustpilot, Airbnb (back-end, user content) | Complete a task |
Decide this first. Different types are designed and built differently.

## 2. Imagery makes or breaks the design
Imagery = photography, illustration, 3D, generated art, textures.
- What it does: **visual interest**, **emotional resonance** ("quicken the pulse"), **communication** (small vs. big business, luxury vs. value).
- Examples:
  - **Line-art loader** that assembles the wordmark: interest beyond plain type.
  - Beautifully lit photography carries an otherwise empty, minimal layout.
  - **Industrial Coatings (3D example):** a rotating, lit **3D shape passes over and under the headline type** as you scroll. It adds depth and interest to a "boring" industry. Then full-bleed artistic photos of turbines and factory staff, composed sculpturally.
  - **French gin brand ✅**: art-directed shots (bottle in front, lemons behind, Breton stripes, bottle in a tree, half-cropped hand), illustration mixed with photos, layered labels for depth. The images evoke the copy (sun, sea, south-west France).
  - **Bad ❌**: washed-out stock family photo + isolated inflatable slide that don't relate, so it feels cheap and homemade. An industrial brand whose guidelines had bespoke imagery but whose site used generic, wrong-scale stock: "let down".
- **Photo checklist:** high-res? in focus? well lit? → best crop? needs grading? retouching? can it be customised to the brand?
- Better imagery makes visitors see the offering as higher quality.

## 3. Bad typography = bad UX
Typography = **choosing fonts** (mood + legibility) + **typesetting** (line length, line height, point size, size contrast).
- **Escape room ❌**: many fonts, small yellow-green type with low contrast over a **moving background**, tight leading, mixed colours, bold and italic everywhere. The user has to work to read it, and it feels cheap.
- **Spectacle maker ✅**: lots of negative space around the title, timeless-modern fonts, good line length, left aligned, black on white, panels aligned to images, big scale jumps from tiny captions to large headlines. Reads one panel at a time.
- **Fonts set the mood (same product, different brands):**
  - *Kinder*: child-like handwritten headlines (each letter different, so it doesn't look like a font) + humanist sans body = playful, family, unpretentious.
  - *Heritage European chocolatier*: elegant italic serif + grotesque sans = old-world, refined, timeless. Swap the type between them and both break.

## 4. "The principle of most important": hierarchy
- **Decide** primary, secondary and tertiary, then express it visually through size and weight. When you emphasise everything, you emphasise nothing. Be decisive and make the contrast big.
- Typical hero order: **1. imagery that tells the story → 2. logo or big headline to orient → 3. value line + CTA** (smaller, but with negative space so it isn't buried).
- **Escape room ❌**: the eye is pulled to the moving background, the busy "Let's party" image and faces, a hard-to-read logo, many stacked medium-sized boxes. No decision was made.
- **Furniture site ✅**: huge furniture image → large split logo (wordmark + icon) → short byline "Furniture designed to last…" + clearly visible button.
- **Sydney Opera House ✅**: lots of changing content, still clear. Full-bleed video bar (1st) → events grouped on white below (2nd) → nav (3rd). Cards in 3 columns, each a unit with a drop shadow; inside each card the photo, then the title, then the text.

## Methods to reuse
1. Before designing, write **site type + primary goal** at the top of the brief.
2. **Art-direct imagery** to match the copy and brand. Mix photo + illustration + layered elements for depth. Never generic stock.
3. Run the **photo checklist** on every image.
4. Pick fonts by **mood** (test by swapping in competitors' type), then typeset (measure, leading, size contrast).
5. Write down the **1-2-3 hierarchy** for each section before laying it out.
6. Group dense content into **card units** (shadow, border or background) inside a grid.
