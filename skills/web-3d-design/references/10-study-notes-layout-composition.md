## Part 1: The 6 levels of movement & flow (basic → advanced)
| Level | Idea | How |
|---|---|---|
| 1. Directional guidance | Tell the eye exactly where to go | Arrows, lines, paths, a model's gaze or limb pointing at the logo/CTA. The eye follows directional cues instinctively |
| 2. Hierarchy-driven flow | An invisible arrow | Visual weight: big/bold → medium → small. Size + contrast set the order, like gravity |
| 3. Layered paths | Main route + micro-routes | Small type blocks create short side loops that rejoin the main path. Keeps people looking longer. Secondary paths must not overpower the main one |
| 4. Implied motion | A still design that feels like it moves | Repetition, progressive scaling, blur, tapering directional patterns, gradients + texture, frozen-action photos (a leap, a splash, swinging fabric), geometric forms that tighten or loosen |
| 5. Flow disruption | Interrupt on purpose to force re-engagement | A bold object across the path (e.g. a black square rotated 45° with a red motif). The brain wants to resolve it, so it pauses. Use it at key messages. It must be intentional |
| 6. **Temporal flow** | Control *when* and *how long* the eye lingers | Beats like music: **impact → linger → release** (punch, slow, pulse). Luxury ads: full-bleed sharp gaze (fast) → fine detail and serif copy (slow) → logo alone in white space (pulse). Apple pages: hero hits → specs in clean blocks → product in open white space |

**Web/3D translation:** temporal flow *is* scroll storytelling. Hero = punch, detail sections = linger, open white-space product moment = pulse or release. On the web you can control the timing literally with scroll and animation (see 04).

## Part 2: Grids
**Why grids:**
1. **They set hierarchy**: span the important element over more columns (Mixd site: body text in 1 column, headline across 2).
2. **Breaking them creates impact**, but only when most elements obey the grid. Break it with one element.
3. **They work for everything**: logos, fonts, posters, web.
4. **They create white space**: choose which cells stay empty. Subdivide (3×4 → 18×24) for micro white space (gaps between lines and tight elements).
5. **They guide the eye**: control line length and calm busy layouts.

**Grid types:**
| Grid | Use | Pro tip |
|---|---|---|
| Baseline | Align body, headlines and captions across columns | Headline leading = multiple of body leading (14pt body → 28pt head). On the web: `line-height` multiples of a 4/8px unit |
| Column (e.g. 4-col) | Magazines, multi-content sites | Let a featured image span 3 columns, text 1 |
| Modular | Product grids, card layouts | **Vary module size by importance** (bestsellers/new = 2-module span) |
| Manuscript | Single column (books, articles) | Margins for notes/images |
| Hierarchical | Modules of different sizes, set up first | Primary bright/bold, secondary muted/smaller |
| Golden ratio (1:1.618) | Logos, proportions | Starting point, not law |
| Asymmetric | Dynamic, editorial, hero-led | Hero takes the big column. Overlap text and image slightly, add diagonals for depth |
| Square | Galleries, Instagram-style feeds | Colour or pattern accents on select squares |
| Rule of thirds | Placing focal points on the intersections | Go slightly off-grid for tension |
| Compound | Column (listings) + modular (details) | Keep breathing room. Combining grids doesn't mean cramming |
| Isometric | 3D-feel illustrations, infographics | Lighter tops, darker undersides for volume |
| Circular | Round/organic logos | Use the negative shapes between elements |
| Triangular | Packaging, geometric patterns | Gradients along the angles, foil at key points |

## Part 3: The LIFT system (advanced layout check)
**L: Leverage point.** The single most important element dominates through **scale, contrast, position, isolation**. Push back anything that competes, and point supporting elements toward it. (Nike: neon-outlined model on misty background, nothing competing; a smaller leverage point = the logo in its own proximity group.) A design can have several leverage points if the brief needs it.

**I: Internal rhythm (eye choreography).** A planned path from the leverage point onward, built from **consistent spacing, predictable alignment, deliberate contrast**.
- Predictable spacing builds trust and relaxes the brain. A well-placed disruption (glowing CTA, 3D object) re-engages attention.
- Speed: **fast rhythm** for simple skimmable content, **slower rhythm** for dense, complex content.
- Questions: How does the eye move? Jumps or smooth? Related things grouped? Spacing consistent?
- **3D web example (Sapforce hero):** giant bold wordmark → a chrome/green-glass 3D object breaking symmetry in the centre → stats and feature list tight on the right → glowing lime "How it works?" CTA circle. A textbook 3D landing page.

**F: Friction & flow.** Friction = tight leading, blurred faces, scribbles, cropped words, awkward type. **Strategic friction is good** *if* flow is kept through clear zones: intense friction zones (top) vs. smooth reading zones (mission statement). Good friction grabs attention. Bad friction loses the message. Check: is this adding clarity or noise? Too many fonts, colours or focal points? "Friction is seasoning."

**T: Transferability.** It must work at every size, format and platform. **Test it:** shrink to thumbnail (still readable and recognisable?), place on dark and light backgrounds, move across formats (mobile, print flyer, motion graphic). The layout flexes and the identity holds.

**Worked example (orange band layout):** L = central orange band (colour contrast, centred, subtle motion) · I = gentle outward pull through spacing and symmetry, steady margin repetition, rhythm between motion and stillness · F = type slightly overlapping the band, non-uniform top-right text, balanced by breathing outer space · T = the band still reads at thumbnail size and across ad, story and hero banner.

## Methods to reuse
1. **Pick the level of flow** the brief needs (1–6). Most web heroes need 2 + 5 + 6.
2. **Beat-map a page** like music: mark each section as punch / linger / pulse / release before designing. Same as a reel shotlist.
3. **LIFT pass** on every comp (questions above). It's also in 06.
4. **Thumbnail + dark/light test** for transferability.
5. **Vary grid module size by importance** in work and product grids.
