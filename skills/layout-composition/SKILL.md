# Layout and composition

From Satori Graphics' layout & composition guide and grid lessons, The Futur (dynamic compositions,
critiques, typography rules) and the design-principles sources. Pair with `design-principles` (C.R.A.P.,
hierarchy, white space) and `typography`.

## Workflow
1. Pick the format and the grid (below). Set margins first; keep them generous.
2. Choose ONE leverage point (the most important thing) and the 1st/2nd/3rd reads.
3. Place the leverage point, then route the eye from it to the CTA/logo.
4. Add friction only where you want a pause; keep everything else calm and aligned.
5. Run the LIFT check and the critique checklist in `design-principles`.

## Eye flow (6 levels)
1. Directional cues: arrows, gaze, pointing, lines lead the eye.
2. Hierarchy flow: big/bold -> medium -> small creates an invisible path (no arrows needed).
3. Layered paths: a main route plus short side loops for detail; side loops stay weaker.
4. Implied motion: repetition, progressive scale, blur, tapering patterns, frozen action.
5. Flow disruption: a deliberate blocker (e.g. a 45° rotated square) to pause on a key message.
6. Temporal flow: punch (hero) -> linger (details) -> pause (white space, logo alone) -> release.
Western readers start top-left; end on the CTA/logo bottom-right unless you deliberately redirect.

## Grids: which and when
| Grid | Use |
|---|---|
| Manuscript (1 column) | Books, long reading, simple slides |
| Column (2-6) | Magazines (3), newspapers (6), print (2); span more columns = more important |
| Modular | Cards, products, galleries; give best-sellers double modules |
| Hierarchical | Modules sized by importance (landing pages) |
| Baseline | Align text across columns; headings at multiples of body leading (14 -> 28 pt) |
| 12-column | Web (8 tablet, 4 mobile); headline 12 cols, paragraph ~6 |
| Rule of thirds | Photos, thumbnails, video frames: subjects on the intersections |
| Golden ratio (1:1.618) | Posters, logos - a starting point, not a law |
| Asymmetric | Hero gets the big area, smaller columns carry secondary info; overlaps add depth |
| Square | Instagram/galleries |
| Compound | Column + modular together |
| Isometric | 3D infographics, buildings, data |
| Circular / triangular | Logos, badges, dynamic packaging |
- Break the grid ONCE for impact, only when everything else obeys it.
- Split big cells into 6 for fine micro-spacing. Be mindful of grid lines: misalignment is the first thing
  critics notice.

## LIFT check
- **Leverage point:** one clear winner via scale, contrast, position, isolation; push back competitors.
- **Internal rhythm:** consistent margins, gutters and spacing build trust; one purposeful disruption
  re-engages. Fast rhythm for skimmable, slower for dense content.
- **Friction and flow:** intentional discomfort (tight leading, cropped words, scribbles, overlaps) in one zone,
  balanced by calm readable zones. For each element ask: clarity or noise? Too many fonts/colours/focal points
  = bad friction.
- **Transferability:** test as a thumbnail, on light and dark, on mobile, print and motion. Hierarchy and
  identity must survive.

## Composition moves
- Dynamic composition = contrast in scale, value and colour (go extreme, then pull back); foreground darker
  and higher-contrast, background lighter.
- Asymmetry must be anchored by a counterweight (a small text block, a line, a shadow).
- Group with thin rules to make dissimilar blocks orderly; align everything to one strong axis.
- Avoid corners and edges unless bleeding off deliberately; leave at least one resting area.
- Expressive layouts: commit - offset, zigzag, use the whole space - but keep the info zone plain and readable.
- Avoid three competing verticals; introduce a horizontal.
- Video frames and thumbnails: rule of thirds, one subject, big readable words, high value contrast, leave room
  for platform UI (captions, buttons).
