# Design principles and critique

Distilled from Jesse Showalter (C.R.A.P.), Kole Jain, Joseph Todaro / Jon Yablonski (Laws of UX),
Juxtopposed, Envato Tuts+, Satori Graphics, GraphiqVibe, a Hindi design playlist and The Futur (Chris Do,
Matthew Encina). Typography details: see the `typography` skill. Grids and eye flow: see `layout-composition`.

## How to use this skill
- **Designing:** decide the #1 thing (focal point) and the 3 hierarchy levels before styling; build on a grid;
  apply the core four; check with the critique checklist before showing the user.
- **Critiquing:** run the checklist, name each problem with the principle it breaks, show the fix (ideally
  apply it with a connector and preview before/after), most impactful fix first. Be direct, like a Futur critique.

## The core four (C.R.A.P.)
| Principle | Purpose | Bad | Good |
|---|---|---|---|
| Contrast | Hierarchy, focal point, interest | Headline same size/weight as body; nothing stands out | Headline much bigger and 2 weights heavier; one accent on the focal object |
| Repetition | Consistency, learnability, brand | "Yard sale": mixed card shapes, images facing different ways | Same card shape, image direction, type styles and colours throughout |
| Alignment | Order, invisible axes | Ragged edges, random centres | Everything on a few shared lines (left edges, baselines); still reads rotated |
| Proximity | Shows relationships | Headline far from its body, buttons scattered | Tight within groups, generous between groups |

## Hierarchy
- Plan levels: 1 hero image/headline, 2 subheads/key graphic/CTA, 3 body/details (2-3 levels per section).
- Marketing order: **attract -> intrigue -> deliver**.
- Tools: size, weight, colour, value (light/dark), position, orientation, isolation (space around it), style
  change. Change one or two at a time.
- Contrast is the master tool (Futur): go extreme first, then pull back. The most important thing must be the
  most prominent - biggest, highest contrast, in front. Foreground = more contrast/darker; background = less
  contrast/lighter. Plan the 1st, 2nd and 3rd read on purpose.
- When two elements compete, make one clearly win.

## White space
- It's an active element. Adding padding is often the single biggest upgrade; packing it in "feels catalogued".
- Micro (letter/line spacing, padding) vs macro (margins, gutters, between sections). Use one spacing scale
  (4/8/16/32...).
- Passive space = legibility; active space = reading order and chunking.
- Mood: lots of space = premium/modern/luxury; tight = energetic/raw; micro-heavy = informative/serious.
- Squint test: groups must read before any words do.
- Space must look intentional; leftover gaps in the wrong place read as mistakes.
- Avoid the corners and page edges unless bleeding off deliberately.

## Balance, unity and the rest
- Symmetrical = stable/calm; asymmetrical = one big element balanced by several small ones (always anchor
  asymmetry with a counterweight); radial = around a focal point.
- Unity/harmony (one family), emphasis (one dominant point), pattern, rhythm (tempo of intervals: tight = fast,
  wide = slow, unexpected gap = jolt), movement (eye path), proportion/scale, variety (controlled tension).
- Contrast types: colour, size, weight, value, shape (angular vs curved), texture, style, light/dark inversion.
- Break repetition once to create a focal point.
- Simplicity: remove anything that doesn't do a job. Too many sizes, weights, colours or "tricks" is the most
  common amateur fault.

## Colour
- Start with ONE primary/brand colour; lighten for backgrounds, darken for text -> a ramp. Add neutrals.
- Semantic: blue trust/links, red danger/urgency/sale, yellow warning, green success. Colour for purpose.
- Pull colours from the logo/brand; check contrast (WCAG: 4.5:1 body minimum, 7:1 ideal).
- Roles: background, text, primary, secondary, accent, semantic, each with shades.
- Pastels = clean/fresh/health/beauty; black-white + one colour = premium editorial.
- Dark mode: lighter cards instead of shadows, softer borders, desaturated chips.

## UI/UX
- Signifiers show what's possible (containers, selected highlight, greyed inactive, hover, tooltips).
- Grids: 12 columns desktop, 8 tablet, 4 mobile; 4-point spacing. One sans family is usually enough;
  large headings -2 to -3% tracking, 110-120% line height; max ~6 sizes on a landing page.
- Shadows: low opacity, high blur; stronger for popovers. If you notice the shadow first, it's wrong.
- Icons at line-height size; buttons padded ~2x height in width; ghost buttons for secondary actions.
- Every action gets a response: button states (default, hover, pressed, disabled, loading); input states
  (focus, error, warning); micro-interactions confirm actions.
- Text over images: gradient or progressive blur, not a flat dark overlay.
- Process: user flow -> wireframes -> design system (colours, type scale, components) -> design -> test. Use
  real copy.

## Laws of UX (quick reference)
Aesthetic-usability, Doherty threshold (<400 ms), Fitts (big, close targets), Hick (fewer choices, split
steps), Jakob (behave like familiar products), Common region, Prägnanz, Proximity, Similarity, Uniform
connectedness, Miller (7±2 per group), Occam's razor, Pareto 80/20, Parkinson, Postel, Serial position
(first/last remembered), Tesler (irreducible complexity), Von Restorff (the odd one out is remembered),
Zeigarnik (unfinished tasks stick).

## Design process
1. Brief: client/brand, audience, goal, tone, deliverables, must-haves. Ask if missing.
2. Research and moodboard (competitors, references).
3. Concept: sketch on a grid; decide focal point and hierarchy before styling.
4. Design, then critique against the checklist; iterate; test at real size and on real media.

## Critique checklist (good vs bad)
1. Can I name the #1 thing within 1 second? (hierarchy, emphasis)
2. Squint: do the groups read? (proximity, white space)
3. Do edges sit on a few invisible lines / the grid? (alignment)
4. Are repeated elements styled identically? (repetition)
5. Is colour limited and purposeful, with readable contrast? (colour)
6. How many sizes, weights, fonts, effects? Cut until each earns its place. (simplicity)
7. Is there somewhere for the eye to rest, and is the space intentional? (white space)
8. Does anything compete with the focal point? Quieten or remove it.
9. Does it work small, on light and dark, on mobile, in motion? (transferability)
10. Does it feel right for the brand/emotion? (spacing, type and colour all set the mood)
