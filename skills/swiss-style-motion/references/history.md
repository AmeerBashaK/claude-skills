# Swiss style: history and designers to borrow from

The International Typographic Style emerged in Zurich and Basel in the 1950s. It values simplicity, legibility and objectivity: sans-serif type, grids, asymmetric layouts. Helvetica (Neue Haas Grotesk, Max Miedinger with Eduard Hoffmann, 1957) and Univers (Adrian Frutiger, 1957) came from it.

| Designer | What to borrow for motion |
|---|---|
| Josef Müller-Brockmann | *Grid Systems in Graphic Design* (1981; grids from 8 to 32 fields). Concert posters (Tonhalle, "der Film"): concentric circles, arcs and bars sized to the grid, implying rhythm. Strict, calm, red/black/white. |
| Armin Hofmann | *Graphic Design Manual* (1965). Point, line and plane; extreme B&W contrast; type and image in tension. Freer with the grid. |
| Emil Ruder | *Typography* (1967). Systematic grid; mixed sizes and weights sharing one x-height/baseline; white space as form. |
| Max Bill / Richard Paul Lohse | Concrete art: modular colour fields and systematic progressions. Great for cell-fill and colour-field sequences. |
| Karl Gerstner | *Designing Programmes*: design as a rule system that generates variants. Perfect for procedural motion. |
| Wolfgang Weingart | Swiss New Wave: breaks and layers the grid, mixed sizes, more energy. |
| Wim Crouwel (Dutch, related) | Grid-built typefaces (New Alphabet), Stedelijk posters. Type built from cells animates well. |
| Contemporary | Experimental Jetset, Mat Voyce (grid-driven kinetic type), Studio Dumbar, brand systems like Spotify Wrapped grids. |
